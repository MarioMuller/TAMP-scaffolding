PSEUDOCODE v2

import final scaffold geometry

for each rod in scaffold:
    calculate heuristic for removing rod
    add candidate to open_list

while open_list not empty:

    take best candidate from open_list
    remove candidate rod from scaffold state
    
    create clean start environment

    if remaining scaffold not structurally valid:
    
	if valid state reachable with amount of robots:
	    run KOMO to find keyframes for:
		    main robot moves to candidate rod
		    main robot grasps candidate rod

		    if candidate_is_currently_supported:
			support robot releases candidate rod
			support robot moves away
		
		    support robots move into place to stabilize unstable rods
		    candidate rod is detached from scaffold
		    main robot moves candidate rod to pickup pose

	    if no keyframes found:
		reject candidate
		continue with next candidate
		
	    else: 
	        plan motion between keyframes
	        save robot paths
	        motion feasible
            

    else check if motion can be found for removing this rod

        run KOMO :
		main robot moves to candidate rod
		main robot grasps candidate rod
		
		if candidate_is_currently_supported:
				support robot releases candidate rod
				support robot moves away
		
		candidate rod is detached from scaffold
		main robot moves candidate rod to pickup pose

        if no keyframes found:
            reject candidate

        else:
            plan motion between keyframes
            save robot paths
            motion feasible

        
    if motion not feasible:
        reject candidate
        continue with next candidate

    if motion feasible:

        store recorded motion for rod & add rod to removal sequence

        if no rods left:
            return removal sequence and recorded paths

        else:
            for each remaining rod:
                calculate heuristic for removing that rod next
                add new candidate to open_list


reverse removal sequence to get assembly sequence
